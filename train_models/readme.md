В данной папке находятся .ipynb блокноты:  
- final_model_train.ipynb - блокнот для обучения финальной модели МО  
- process_dataset_with_embedding_creation.ipynb - блокнот для предобработки входных данных  
- train_models.ipynb - блокнот для подбора гиперпараметров, обучения, сравнения нескольких моделей машинного обучения, и проведения ablation study для модели BiLSTM. Разбиение на тренировочное, валидирующее и тестовое множество следующее: тренировочное множество - с 1924 до 2021 года включительно, валидирующее множество - с 2022 до 2024 года включительно,тестовое множество - начиная с 2025 года

# Описание блокнота process_dataset_with_embedding_creation.ipynb  
Данный блокнот принимает на вход необработанный датасет raw_dataset.txt, полученный в результате работы программы для парсинга (находится в этом же репозитории, в папке parsing).  
Датасет raw_dataset.txt, созданный в апреле 2026 года, можно найти по [ссылке](https://drive.google.com/file/d/14xv5QUKM28GDjCJjGnYjWrNdyqmabNSU/view?usp=sharing)  
В ходе обучения, обучались эмбеддинги Entity Embeddings для признаков "swimmer_id", "host_country_code", "swimmer_country_code", обученные при помощи MLP (создан при помощи keras+tensorflow)  
Блокнот предобрабатывает данный датасет, и создает следующие файлы:  
- dataset_with_embeddings.csv - предобработанный датасет в формате csv  
# Описание блокнота train_models.ipynb  
Данный блокнот принимает на вход обработанный датасет dataset_with_embeddings.csv, полученный в результате блокнота process_dataset_with_embedding_creation.ipynb.  
Датасет dataset_with_embeddings.csv, созданный в апреле 2026 года, можно найти по [ссылке](https://drive.google.com/file/d/1s8CIMW7YuQPIKxzzPo5o6fxxqgUHFMuX/view?usp=sharing)  
Блокнот сравнивает несколько методов МО:  
- ElasticNet (из библиотеки scikit-learn)  
- RandomForestRegressor (из библиотеки scikit-learn)  
- XGBRegressor (из библиотеки XGBoost)  
- LinearSVR (из библиотеки scikit-learn)  
- MLP (созданный с помощью библиотек keras+tensorflow)  
- BiLSTM (созданный с помощью библиотек keras+tensorflow)  
  
Гиперпараметры подбирались с помощью GridSearch (по метрике MAE). Модели сравниваются по 3 метрикам: R^2, MAE, MAPE. В результате, лучшей моделью по всем метрикам оказалась модель BiLSTM.  
Также, строятся графики ошибок на тренировочном+валидационном и тестовом множествах для моделей в зависимости от номера итерации/номера эпохи/числа деревьев.  
Также, строятся диаграммы рассеяния для каждой модели (реальное значение и предсказываемое) на тестовом множестве.  
Также, строятся графики метрик MAE, MAPE, и R^2 для разных моделей в зависимости от дистанции.  
Также было проведено ablation study для созданной модели BiLSTM, с целью удостовериться, что все её элементы необходимы для более точного предсказания. Сравниваемые в ходе ablation study альтернативы:  
1.	LSTM с эмбеддингами от MLP - модель с заменой блоков BiLSTM на LSTM (Long Short-Term memory, «долгой краткосрочной памяти») и с использованием эмбеддингов, обученных с помощью MLP.  
2.	LSTM с удвоенным числом LSTM блоков и эмбеддингами от MLP – модель с заменой блоков BiLSTM на в два раза большее число LSTM блоков, чем было BiLSTM блоков и с использованием эмбеддингов, обученных с помощью MLP.  
3.	LSTM с встроенными эмбеддингами - модель с заменой блоков BiLSTM на LSTM и с использованием эмбеддингов, обученных вместе с этой моделью.  
4.	LSTM с встроенными удвоенным числом LSTM блоков и эмбеддингами – модель с заменой блоков BiLSTM на в два раза большее число LSTM блоков, чем было BiLSTM блоков и с использованием эмбеддингов, обученных вместе с этой моделью.  
5.	BiLSTM без эмбеддингов – BiLSTM модель, не использующая эмбеддинги для id пловца, кода страны проведения заплыва и кода страны рождения пловца.  
6.	BiLSTM с эмбеддингами от MLP – модель, аналогичная исходной модели BiLSTM. Использует эмбеддинги, обученные с помощью MLP.  
7.	BiLSTM с встроенными эмбеддингами - модель, аналогичная исходной модели BiLSTM, с отличием в том, что она использует эмбеддинги, обученные вместе с этой моделью.  
  
В результате, по метрикам R^2 и MAE победила модель BiLSTM с эмбеддингами от MLP (исходная). Было решено её и использовать как финальную модель.  
# Описание блокнота final_model_train.ipynb  
Данный блокнот обучает финальную модель BiLSTM, которая будет использоваться в системе.  
На вход принимает необработанный датасет raw_dataset.txt, полученный в результате работы программы для парсинга (находится в этом же репозитории, в папке parsing).  
Датасет raw_dataset.txt, созданный в апреле 2026 года, можно найти по [ссылке](https://drive.google.com/file/d/14xv5QUKM28GDjCJjGnYjWrNdyqmabNSU/view?usp=sharing)  
На выходе получаются следующие файлы:  
- BiLSTM_model.keras - модель BiLSTM keras  
- SequenceStandardScalerForBiLSTM.py -  код класса - предобработчика входных признаков  
- features_preprocessor.joblib - предобработчик входных признаков  
- swimmer_country_embedds.joblib - словарь для перевода кода страны пловца в соответствующий эмбеддинг  
- swimmer_id_embedds.joblib - словарь для перевода id пловца в соответствующий эмбеддинг  
- host_country_embedds.joblib - словарь для перевода кода страны заплыва в соответствующий эмбеддинг  
Все эти файлы будут использоваться в серверной части веб-приложения.
