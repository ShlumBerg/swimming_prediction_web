# Описание репозитория  
В репозитории есть 3 папки:
- parsing - код программы для парсинга данных с API World Aquatics  
- train_models - код jupyter ноутбуков для предобработки датасета; для обучения и сравнения разных моделей МО; для создания финальной модели МО  
- website - код веб-приложения, использующего обученную модель МО.
