Данная папка содержит файлы, необходимые для развертывания веб-приложения для предсказания результатов по плаванию  
Здесь содержатся следующие файлы:  
- backend - код серверной части приложения  
- frontend - код HTML страниц приложения  
- e2e_tests - код автотестов для записи демонстрации работы приложения и для проверки его работоспособности (сквозное тестировани веб-приложения при работе через веб-интерфейс)  
# Развертывание приложения на сервере  
Для развертывания приложения на сервере, необходимо скопировать на веб-сервер содержимое папок frontend и backend.  
Далее, необходимо открыть терминал сервера в папке backend. В нем необходимо создать виртуальное окружение python (рекомендуется версия python 3.13):
```
python3.13 -m venv .venv
```
Далее, необходимо активировать виртуальное окружение python:  
Для linux ubuntu 24.04.4 LTS:
```
source .venv/bin/activate
```
И установить все зависимости для работы системы:  
```
pip install -r requirements.txt
```
Далее, необходимо запустить fastapi сервер:  
```
fastapi run main.py
```
Далее, необходимо открыть порт 8000 для того, чтобы внешние компютеры могли общаться с fastapi-сервером:  
Для linux ubuntu 24.04.4 LTS:  
```
sudo ufw allow 8000
```
После этого сервер станет доступен по протоколу http по порту 8000.
