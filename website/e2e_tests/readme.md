Данная папка содержит файлы, необходимые для тестирования развернутого веб-приложения для прогноза результатов плавания и записи демонстрации его работы  
Здесь содержатся следующие файлы:  
- demo.py - код для создания видеодемонстрации работы веб-приложения  
- main.py - код HTML страниц приложения  
  
И папка demo_videos (в ней хранятся результаты - записанные видо демонстрации работы системы).  
Для записи демонстрации работы приложения или его тестирования, необходимо развернуть его на сервере.  
Помимо этого, при запуске файлов main.py или demo.py необходимо работать из виртуального окружения. Для этого:  
Необходимо открыть терминал сервера в папке e2e_tests(этой). В нем необходимо создать виртуальное окружение python (рекомендуется версия python 3.13):
```
py -m venv .venv
```
Далее, необходимо активировать виртуальное окружение python:  
Для Windows:  
```
.venv/Scripts/activate
```
И установить все зависимости для работы системы:  
```
pip install -r requirements.txt
```
Также, необходимо установить браузеры для автоматического тетсирования системы в них:  
```
playwright install
```
Кроме того, необходимо в файле main.py поменять значение константы BASE_URL_DEFAULT на адрес развернутой системы.
# Запуск сквозного тестирования системы  
Для сквозного тестирования системы, необходимо в терминале с активированным виртуальным окружением python запустить следующую команду:  
```
pytest --browser=chromium --browser=firefox --browser=webkit main.py main.py
```
Данная команда проведет тестирование системы на 3 браузерах с 3 различними движками: webkit, chromium и gecko и с 6 различными разрешениями экрана.  
# Создание видеодемонстрации работы системы  
Для создания видео с демонстрацией работы системы, необходимо в терминале с активированным виртуальным окружением python запустить следующую команду:  
```
pytest --browser=chromium demo.py --video=on demo.py -k="xxl" -output="demo_videos"
```
Видео работы системы будет представлено в папке demo_videos.
