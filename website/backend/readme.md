Данная папка содержит файлы бэкенд-части для работы веб-приложения для прогнозирования результатов по плаванию и тесты для API.  
Инструкция по развертыванию приложения на сервере представлена в родительской папке.  
# Как запустить тесты для API  
Для запуска тестов API, необходимо, сначала, запустить систему.  
## Запуск системы  
Необходимо открыть терминал сервера в папке backend. В нем необходимо создать виртуальное окружение python (рекомендуется версия python 3.13):  
```
python3.13 -m venv .venv
```
Далее, необходимо активировать виртуальное окружение python:  
Для linux ubuntu 24.04.4 LTS:
```
source .venv/bin/activate
```
И установить все зависимости для работы системы:  
```
pip install -r requirements.txt
```
Далее, необходимо запустить fastapi сервер:  
```
fastapi run main.py
```
## Тестирование API  
Когда сервер запущен, необходимо открыть терминал сервера в папке backend. Далее, необходимо активировать виртуальное окружение python:  
Для linux ubuntu 24.04.4 LTS:  
```
source .venv/bin/activate
```
Далее, необходимо запустить тесты:  
```
pytest test_main.py
```
